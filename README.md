# YJ-关机助手

Windows 定时关机桌面小工具，简洁好用。

## 功能

- **快速关机**：3分钟 / 10分钟 / 30分钟 / 60分钟 一键关机
- **定时关机**：选择日期和时间，精确到秒
- **倒计时显示**：剩余时间实时更新
- **取消关机**：一键取消已设置的关机任务

## 授权模式

- 试用1天（全功能）
- 注册试用7天（输入邮箱）
- ¥9.9 永久解锁

双击运行 `YJ-关机助手_v00.33.exe`，无需安装。
